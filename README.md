# 🔥 FireGuardAI

# AI-Powered Thermal Fire Detection & Risk Intelligence Platform

FireGuardAI is a web-based fire-risk monitoring and intelligence platform designed to help users monitor thermal events, identify potential fire threats, manage alerts, visualize geographic risk, analyze situations, and generate structured operational recommendations.

The project combines a web-based frontend with a Python Flask REST API and a structured risk-analysis engine.

## 🤖 AI Analyst

### Open:

https://fireguardai-1-oo5t.onrender.com/analyst.html

The AI Analyst allows users to enter a situation using natural language and receive a structured risk assessment.

It provides:

- Threat level
- Risk score
- Thermal signal
- Industrial proximity
- Population exposure
- AI confidence
- Explanation
- Recommended response

### Example:

```text
A normal clear day with no unusual thermal activity,
no smoke, and no fire detected in the monitored region.
```
